# Issue #404: FAQ section with FAQPage schema

As of 2026-10-05, branch `feature/404-faq`. Last of the AI visibility issues #400–#404.

## Decisions

- **Data:** optional `faq` (headline, title, description, `items` of question/answer) in the `home` collection (`content/index.yml`), next to the other home sections. Shops without `faq` render nothing; La Fattoria has its own `index.yml`, so nothing changes there until it adds questions.
- **Place:** home page, above the closing CTA. `/zahlung-und-versand` stays a Markdown page.
- **Markup:** native `<details>`/`<summary>` instead of `UAccordion`. Reka's accordion unmounts closed panels by default, so the answers would be missing from the SSR HTML that crawlers read; `<details>` keeps them in the markup, is keyboard accessible and adds no JavaScript or Nuxt UI theme (#314, #319).
- **Answers are plain text** (no Markdown/links), so the same strings work in the HTML, the JSON-LD and `/llms.txt`.
- Google shows FAQ rich results only for authoritative sites since 2023; the point is AI answers and on-page clarity.

## Implementation

- `buildFaqPageSchema` in `app/utils/schema.ts`; `Home/Faq.vue` emits it via `useHead` (key `jsonld-faq`).
- `/llms.txt` gets a "Häufige Fragen" section after "Bestellen" (`queryCollection(event, "home").select("faq")`).
- Demo FAQ in `content/index.yml` with the facts from `zahlung-und-versand.md`. Note: the delivery info card in the same file says "darunter 1 € Liefergebühr", the payment page and the FAQ say 2 €.

## Verification
